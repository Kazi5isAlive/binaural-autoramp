# Binaural Auto-Ramp

Tom Campbell / My Big TOE–style **auto-ramping binaural beats** trainer.

Press **Start Auto-Ramp** and the session runs by itself: ramp in → hold at target theta → steeper ramp out toward beta.

## Features

- Meditator presets: Good / Fair / Poor (different ramp-in starts)
- Targets: 4 Hz, 3.8 Hz, 3.75 Hz
- Base carriers: 100 / 500 / 2000 / 5000 Hz
- Adjustable step duration & hold length
- Click-free Web Audio oscillators (stereo: L = base, R = base + beat)
- Save named configurations for month-long experiments
- Dark meditation UI

**Stereo headphones required.**

These are training wheels — eventually practice without beats.
